# Punti e Linee

Il classico gioco carta e matita (Dots and Boxes) nel browser.

- contro il computer, con 4 livelli e una modalità adattiva che impara il tuo stile;
- in più persone sullo stesso dispositivo;
- a distanza: crei la partita, mandi il link a un amico e giocate ognuno dal suo telefono.

Gioca qui: https://tomelleridavide3d-prog.github.io/punti-e-linee/

Il gioco a distanza usa [PeerJS](https://peerjs.com) (licenza MIT), incluso in `peerjs.min.js`.
