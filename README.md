# Linee e quadrettini birichini

di Tomelleri Davide per RH group

Il classico gioco carta e matita "punti e linee" (Dots and Boxes), da giocare con un amico a distanza: crei la partita, mandi il link e giocate ognuno dal suo telefono.

Gioca qui: https://tomelleridavide3d-prog.github.io/punti-e-linee/

Il gioco a distanza usa [PeerJS](https://peerjs.com) (licenza MIT), incluso in `peerjs.min.js`.
